## 🌐 Free 1-Click Deployment Options

### Vercel / Netlify
1. Push this folder to a GitHub repository on your GitHub account (`github.com/Ngabo23`).
2. Log into [Vercel](https://vercel.com) or [Netlify](https://netlify.com) using your GitHub account.
3. Select your repository.
4. Set Build Command: `npm run build` and Output Directory: `dist`.
5. Click **Deploy**!
